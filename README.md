# C# Desktop Application

A Windows desktop application built at De Montfort University (2025).

## What I built
- A three-layer architecture (GUI, program logic and database storage)
- Forms with navigation and user-friendly layouts
- Database connection with create, read, update and delete operations
- Input validation, registration and login

## Tools
C#, Visual Studio, SQL

## How to run
1. Install Visual Studio.
2. Download this repository and open the `.sln` file.
3. Press Start to run the app.
